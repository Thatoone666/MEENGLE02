## ?? Apple-Style Pricing Psychology

### 1. **Charm Pricing** (The .99 Effect)
```
$9.99  vs  $10.00  = Feels significantly cheaper
$16.99 vs  $17.00  = Psychological anchor
$24.99 vs  $25.00  = Creates perception of deal
$34.99 vs  $35.00  = Premium pricing without sticker shock
```

### 2. **The Anchor Effect**
```
Spark ($9.99) anchors everything else as "more premium"
Spark+ ($16.99) becomes the middle ground
Flame ($24.99) becomes expensive but justified
Wildfire ($34.99) seems like the "all-inclusive" option
```

### 3. **Savings Display**
- Spark+: **32% savings** (highest percentage = best deal perception)
- Wildfire: **30% savings** (close to middle = seems fair)
- This psychological equality reduces guilt about paying more

### 4. **Free Trial (Premium Only)**
- Risk removal for hesitant customers
- High conversion (70%+ industry average)
- Creates commitment/habit formation
- Increases lifetime value

### 5. **Visual Hierarchy**
```
Spark       [Normal]
Spark+      [HIGHLIGHTED - "Most Popular" badge]
Flame       [Normal]
Wildfire    [GOLDEN/PREMIUM - "BEST VALUE" badge + Free Trial]
```

### 6. **Feature Justification**
```
Spark ? Spark+:     +69% price  = +100% features (GOOD)
Spark+ ? Flame:     +47% price  = +30% features (OK)
Flame ? Wildfire:   +40% price  = +50% features (BEST DEAL)
```

## ?? Billing Flexibility

### Weekly Billing
- Lowest commitment
- Easy to cancel
- Higher churn rate
- Good for trial users

### Monthly Billing
- Better savings (17-32% discount)
- Standard SaaS option
- Lower churn than weekly
- Preferred by committed users

### Bundle Discounts
```
3-month commitment:  10% extra discount
6-month commitment:  15% extra discount
12-month commitment: 25% extra discount (Best for retention)
```
